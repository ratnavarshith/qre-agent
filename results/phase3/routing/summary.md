# Cost routing, simulated from the four-model eval

Generated by `scripts/routing_sim.py` from the stored runs (grader v2) of gemini-2.5-flash and claude-sonnet-5: 40 tasks × 3 passes, no API calls. Pass i of Gemini is paired with pass i of Sonnet (seed i). An escalated task is graded on Sonnet's run and costs Gemini's LLM calls up to the switch plus Sonnet's whole run (a fresh start). Costs are ours (`budgets.yaml` prices, as in the eval). Values are mean ± sample standard deviation across the passes (min–max). Unlike the eval summary, Gemini's one api-error run counts as a failure (escalated by c and d).
