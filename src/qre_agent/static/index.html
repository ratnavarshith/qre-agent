Quantum resource estimates

This is a student project about how many physical qubits and how much time a quantum algorithm needs once you add error correction. You type a problem in plain English, an LLM agent builds the circuit and runs two estimators (Microsoft's QDK for the surface code, IBM's bicycle compiler for the gross codes), and a separate checker compares the numbers in the answer to what the tools actually returned. It runs on a small budget so it can stop for the day, and the agent still gets things wrong sometimes, which is why the checker is there.

Code, results and write-up: github.com/ratnavarshith/qre-agent
